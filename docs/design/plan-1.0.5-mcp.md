# FutureShell 1.0.5 开发计划

更新于 2026-11-07。代码基线为 `v1.0.4`（`e0a69bf`）。本文供范围确认、开发、复审和验收使用。当前 `release/1.0.5` 已进入实现与验证阶段，本地结果见第八节，三平台 CI 与正式制品待核对。1.0.5 增加外部 MCP 的文件上传下载、传输管理、远端文件管理和 SSH 会话管理。所有新入口都会出现在「设置 → AI → 对外 MCP 服务」的工具授权清单中。

## 一、现状与交付目标

| 当前能力 | 1.0.5 要补齐的部分 |
| --- | --- |
| 外部 MCP 已能发现、打开和列出 SSH 会话，读取终端并提交输入。 | 可以查看连接详情、关闭会话和请求重连，并确认实际结果。 |
| 外部 MCP 的 `sftp.list`、`sftp.read`、`sftp.write` 提供目录输出及文本读写。桌面 SFTP 面板已有二进制文件传输。 | 让外部客户端通过受授权的本地路径上传文件，或下载到本地沙箱。调用后可查询进度、最终结果与错误，也可取消。 |
| 应用已有远端属性查询、递归枚举及常用文件操作。 | 为每项操作提供独立的 MCP 工具与结构化结果，删除单独授权。 |
| 内置 Agent 声明了 `sftp_get`、`sftp_put`，现有应用端实现会返回「未实装」。 | 本版以已工作的桌面传输引擎作为外部 MCP 入口的基础。 |

本版覆盖单文件上传下载、同一 SSH 连接内的远端文件和目录操作。跨主机复制、批量传输、任务跨应用重启恢复、RDP、串口及内置 Agent 工具接线留在后续版本。工具直接以 SSH 会话端点为目标。仅在堡垒机菜单中切换主机的 PTY，需要另有实际到该主机的 SSH/SFTP 连接才可传文件。

依据 [外部 MCP 工具清单](../../crates/mcpbridge/src/tool.rs)、[桌面传输入口](../../app/src/commands/sftp_cmd.rs) 与 [内置 Agent 端口](../../app/src/agent/exec_port.rs)。

## 二、文件传输与任务管理

### 工具契约

工具名为拟定接口。标为 ID 的值由工具返回，调用方原样传回。

| MCP 工具 | 输入 | 输出及判据 |
| --- | --- | --- |
| `sftp.upload` | `session_id`、`local_path`、`remote_path` | 入队成功返回 `transfer_id`。源为经本机授权的普通文件，支持二进制。 |
| `sftp.download` | `session_id`、`remote_path` | 入队成功返回 `transfer_id`。目标由应用根据下载沙箱与远端路径确定，结果提供沙箱相对路径。 |
| `transfer.list` | 可选 `session_id` | 列出本次应用运行中仍可查询的 MCP 传输，返回任务 ID 与摘要。 |
| `transfer.status` | `transfer_id` | 返回会话、方向、状态、进度字节、总字节、脱敏错误及校验结论。总大小未知时返回空值。 |
| `transfer.cancel` | `transfer_id` | 返回取消请求已受理、已处于终态或任务不可用。是否真正取消，以后续查询的终态为准。 |

### 共用传输链路

- 从桌面 `transfer_submit` 抽出提交核心，复用会话传输管理器、端点锁、临时件、提交和校验逻辑。GUI 继续接收原事件。传输进度由现有单消费者事件泵写入应用侧查询快照，MCP 轮询快照。已有传输引擎允许 worker 在提交返回前发出终态，登记与更新必须支持这个顺序。
- 对外使用不可猜测的字符串任务 ID，应用内部映射到引擎 ID、原会话和连接代次。状态查询限 MCP 创建的任务。活跃任务保留到终态或应用退出，终态采用有界缓存。首版拟保留最近 256 条终态且最长 1 小时。未登记、已过期和应用重启后的句柄返回同一种不可用错误。关闭会话后仍可在保留期内核对已知终态，取消只向原管理器发送信号。
- 对外区分 `queued`、`running`、`retrying`、`cancel_requested`、`completed`、`failed`、`cancelled`。文件交付与校验结果分开呈现。哈希通过、仅大小对照、未校验、校验失败分别可见。取消与提交同时发生时报告真实终态，先完成的文件保留。失败或取消保留的临时件沿用引擎规则，本版未提供 MCP 续传参数或自动重放。提交超时或回包丢失时，先用列表核对是否已受理。
- 上传源使用用户在连接编辑器明确选择的本地目录，默认为未授权。路径以该目录为基准，拒绝越界、软链接逃逸、非普通文件与打开时发生的替换。目录授权存于本机设置，外部连接配置导入不带此授权。下载复用现有沙箱选择规则和远端路径映射，工具参数无法改写沙箱根。目录创建、临时件写入和最终提交均验证边界。
- 文件数据经 SFTP 传输，MCP 返回任务元数据和结果。上传、下载默认拒绝覆盖，冲突保护必须在最终提交处成立。若目标服务器或文件系统无法提供可靠的不覆盖语义，返回可诊断错误。GUI 原有覆盖行为由其原路径保留。

依据 [传输管理器和事件状态](../../crates/sshengine/src/transfer.rs)、[应用传输提交和事件泵](../../app/src/commands/sftp_cmd.rs) 与 [本地沙箱实现](../../crates/sshengine/src/sandbox.rs)。

## 三、远端文件管理

| MCP 工具 | 拟定语义 |
| --- | --- |
| `sftp.stat` | 输入 `session_id`、`path`，返回大小、类型和可用的修改时间。软链接类型及目标单独呈现，属性查询沿用现有 `lstat` 语义。 |
| `sftp.walk` | 输入 `session_id`、`path`、可选排除条件，返回相对路径、文件、目录和跳过的软链接。复用现有递归深度、条数和截断检查，并设置响应预算。 |
| `sftp.mkdir` | 在指定路径创建单级目录。父目录缺失、同名文件存在等情况以错误返回。 |
| `sftp.rename` | 输入 `from`、`to`，覆盖重命名和同一远端文件系统内的移动场景。目标已存在时拒绝，跨文件系统按服务端结果报告。 |
| `sftp.copy` | 同一 SSH 会话内复制文件或目录。以 SFTP 流式读写复用引擎，保留目录结构和空目录。递归复用有界枚举，软链接和特殊文件在开始前明确报告。 |
| `sftp.delete` | 单独授权，默认关闭。普通文件、链接和空目录可单项删除，非空目录必须显式传 `recursive: true`。拒绝根路径和歧义目标，递归不跟随链接。 |
| `sftp.symlink` | 显式区分 `target` 与 `link_path`。使用已有 SFTP 软链接原语，服务器不支持时返回工具错误。 |

写操作执行前绑定当前会话代次，默认拒绝覆盖。现有 GUI 复制走 `cp -Rf`，覆盖移动可能先删目标，外部入口使用能够验证不覆盖条件的操作。复制首先校验源和目标关系，拒绝把目录复制到自身或其后代。递归删除先做有界预检，执行中遇到变化或失败时返回已完成数量及失败位置。目录复制失败时如实报告部分结果，清理只涉及本次创建且能确认归属的临时件。

依据 [SFTP 元数据、枚举和删除原语](../../crates/sshengine/src/sftp.rs)、[应用远端文件操作](../../app/src/commands/fileops_cmd.rs) 与 [现有复制命令](../../crates/sshengine/src/fileops.rs)。

## 四、SSH 会话管理

| MCP 工具 | 拟定语义 |
| --- | --- |
| `sessions.details` | 输入 `session_id`，返回连接名、当前 SSH 端点、实际状态及连接代次。公开主机密钥指纹仅在能与本代连接对应时返回。无凭据、用户名、代理环境和其他本地路径。 |
| `sessions.close` | 关闭指定 SSH 会话，复用应用的传输收尾、终端关闭和会话事件。若存在进行中的传输，返回冲突并让客户端先取消或等任务完成。 |
| `sessions.reconnect` | 请求已登记的断线 SSH 会话重连，返回受理、已有重连在进行或拒绝。客户端通过详情确认新代次及连接结果。 |

- 提取共享的 SSH 关闭与重连入口，复用注册表、重连互斥和生命周期收尾。关闭和重连使用服务端在调用开始时捕获的连接代次，确认后复核。关闭前检查活跃任务与阻止同代新提交须在同一会话生命周期边界收敛。关闭失败后重新查询状态，重连请求无需并发重发。
- 详情使用运行时连接事实。当前 GUI 详情会回查可编辑的连接配置，MCP 详情使用建立连接时确认的端点，区分 `connected`、`disconnected`、`reconnecting`。已关闭和未知会话统一返回不可用。MCP 发起重连时，在每次拨号前核对仍获准使用 SSH 配置。配置指向另一端点时，返回错误并提示由用户重新打开连接。原会话的主机密钥与认证流程继续生效。
- 新工具按各自权限管理。已有 1.0.4 会话、终端和文件工具的参数及回包保持兼容。

依据 [会话注册表与连接代次](../../app/src/sessions.rs)、[关闭和重连流程](../../app/src/commands/session_cmd.rs) 与 [GUI 连接详情](../../app/src/commands/monitor_cmd.rs)。

## 五、授权、审计与兼容

- 15 个工具分别勾选，默认全部关闭。传输列表和状态、文件属性和枚举、连接详情走只读档。上传、下载、取消、文件变更、关闭与重连至少为写入档，下载涉及本地落盘。删除独立授权并按危险等级处理，需确认档走强确认，用户明确启用免确认时沿用该档位。独立授权、路径、连接代次及沙箱限制在各档位均适用。
- 只有当前允许 MCP 使用的 SSH 配置可发起新任务或操作远端。撤销配置许可后，任务列表省略该配置的任务。持有已返回的任务 ID 且具有相应工具授权时，仍可查询不含路径的状态摘要或请求取消已接收的任务。1.0.4 的本机令牌与工具名单为共享边界，任务 ID 不替代授权，也不引入按客户端身份隔离的承诺。工具名单仍在客户端建立连接时读取，设置页保留重连提示。
- 工具响应提供结构化错误与下一步提示，区分权限拒绝、未知目标、越界、目标已存在、服务端不支持、部分完成和超时。审计区分申请、受理与实际完成，关联任务 ID 与会话。数据内容、访问令牌与凭据不进入日志。工具回包、审计路径和错误文本继续走脱敏。
- 版本升级复用现有设置存储，不计划新增数据库迁移。回退先取消授权并重连，等待或取消进行中的任务，再按测试环境核实的数据备份流程回退程序。已交付文件、已删除路径及远端目录的部分结果由操作者核对，程序回退无法恢复远端变更。

## 六、让 AI 从工具清单识别使用方式

- 每个工具都有独立名称、用途描述和参数 schema。说明必填字段、默认值、路径基准、是否修改数据、是否异步和适用的会话类型。任务 ID 和会话 ID 由查询返回并原样传递。
- 上传和下载的受理结果直接提供任务 ID、当前状态及后续查询工具提示。重连结果指向连接详情查询。错误返回稳定错误码、可读原因和适用的下一步，未知执行结果要求先查状态，避免重复提交。
- 描述明确 SFTP 和 SSH exec 的目标是原始连接端点。交互终端中经堡垒机菜单选中的机器，不据此推断为文件工具的目标。连接详情提供可核对的运行时端点。
- 工具清单中的示例只使用合成路径和标识。文件操作使用结构化参数，交互终端沿用 1.0.4 的按键和提交能力。新功能所需的调用方法应能从清单和返回值中取得。
- 实际 AI 验收使用新客户端，只提供已授权的合成连接名、文件位置和任务目标。检查其能否自行发现入口、选择正确会话、完成操作并核对结果，将失败原因分为工具描述、参数契约、权限、连接与服务器能力问题。

各阶段验收都须保留输入、可观察结果和失败原因。先锁定任务状态及路径契约，再做外部入口和实际 AI 客户端联调。工期根据跨平台文件操作能力与联调结果确定。 [开发与发布指南](../../CONTRIBUTING.md#发布流程)
